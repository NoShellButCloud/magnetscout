Avvio in tre passi

Serve solo Python 3.9 o successivo. Niente pip, niente dipendenze, niente build.

Clona il repository

git clone https://github.com/NoShellButCloud/magnetscout.git
cd magnetscout

Avvia il server

python server.py

Solo libreria standard: nessuna installazione aggiuntiva.

Apri il browser

Si apre da solo su http://127.0.0.1:8765/. L'host è limitato a localhost: l'interfaccia non è raggiungibile dalla rete.

Perché non funziona direttamente su GitHub Pages

GitHub Pages serve solo file statici. MagnetScout invece è composto da un server Python che interroga gli indici, fa da proxy DNS, parla IRC e riceve i file via DCC, e da un'interfaccia che chiama le sue API. Pages non esegue Python, non apre connessioni verso IRC e non può scrivere file sul tuo disco; inoltre gli indici non consentono chiamate dirette dal browser (CORS).

Per questo questa pagina è una vetrina: l'unico modo per usare il programma è avviarlo sul tuo computer. Non esiste e non è previsto un backend pubblico del progetto.
